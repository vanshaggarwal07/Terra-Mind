# twin-web

Next.js (App Router, TypeScript) frontend. The Digital Twin UI: map,
locality timeline, Future Intelligence Score card, RERA builder card,
copilot chat, review dashboard, and ops.

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

Feature pages are built in Phase 2 (**P2.7 - P2.11**).
