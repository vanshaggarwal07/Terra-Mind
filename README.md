# Terra-Mind

Property intelligence platform for the Noida · Greater Noida · Yamuna Expressway · Jewar Airport corridor.

The application is a Next.js app that lives in [`terra-mind/`](terra-mind/README.md) — see its README for setup, environment variables, and the Corridor Signal Feed docs.

## Quickstart

```bash
cd terra-mind
npm install
cp .env.example .env.local   # then fill in secrets
npm run dev                  # http://localhost:3000
```

## Repository layout

```
terra-mind/   Next.js app (frontend + API routes)
```
